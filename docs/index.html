The problem

One global state machine, corrupted by a crowd.

Port knocking hides a service behind a secret sequence of connection attempts on closed ports. Complete the sequence in time and the firewall opens for your IP. It works — until more than one client knocks at once.

● classic knockd

Shared state, cross-talk

One global set of door state machines is advanced by whatever packet arrives next, from anyone. Interleave two sequences and each client bumps the other's progress — sequences corrupt, and legitimate knocks silently fail.

A :7000  B :7000  A :8000  B :8000
global step → 1 → 2 → 3 → ✗ desynced
neither door opens reliably
◆ knock-daemon

One lane per source IP

Matching state is partitioned by source address and sharded across worker threads. Client A's progress lives in A's lane; B's in B's. Interleaving is invisible — each sequence advances on its own, to its own door.

A → step 1 → 2 → 3 → ✓ open
B → step 1 → 2 → 3 → ✓ open
both open, fully interleaved
How it works

A packet's path, from the wire to the door.

Four stages, each swappable at a trait boundary — capture backend and firewall backend are chosen at build time and in config.

01 · capture

Off the wire

Pure-Rust AF_PACKET — no libpcap — or a libpcap backend. A kernel cBPF prefilter sheds non-door traffic before it reaches userspace.

02 · parse

Decode frames

One unit-tested decoder reads IPv4 / IPv6 down through VLAN and QinQ tags to the port and flags — the source of truth.

03 · match

Per-source lane

Sharded by source IP across worker threads. Each door is an ordered sequence with its own seq_timeout; an optional per-source rate limiter caps the noise.

04 · open

Grant access

The nftables backend adds the source to an allow-set with a kernel-side timeout; or the command backend runs your shell with %IP%.

What ships

Built to run as a service, not a script.

◆ Two capture backends

Pure-Rust AF_PACKET with zero libpcap dependency, or a libpcap path — same tested frame decoder behind both.

◆ nftables & command

Atomic nftables allow-set with a kernel-expiring timeout, or a knockd-style shell command with %IP% substitution.

◆ knockd drop-in

Parses classic knockd.conf files so you can migrate an existing setup without rewriting your doors.

◆ Sharded matching

Work fans out across threads by source IP, with an optional per-source token-bucket rate limiter.

◆ Prometheus /metrics

Knocks accepted, kernel packets and drops, and per-backend counters on a scrapeable endpoint.

◆ Runs unprivileged

A hardened systemd unit grants just CAP_NET_RAW and CAP_NET_ADMIN — no root.

◆ Self-contained binaries

Static musl and glibc tarballs plus .deb / .rpm for x86_64 and aarch64. Verified by SHA256SUMS.

◆ Memory-safe Rust

A root-adjacent network daemon with no GC and no C parsing surface of its own. Rust 1.80+.

◆ Prove it offline

--demo replays interleaved clients with no root and no capture; --check validates a config.

Install

See the interleaving in one command.

No root, no libpcap, nothing to capture — --demo replays two clients knocking the same door with fully interleaved packets and shows both accepted. The exact case classic knockd mishandles.

knockd2 — demo 
# prove the concurrency, no privileges needed
$ cargo run -- --demo

  client 10.0.0.14 → 7000 …… 8000 …… 9000
  client 10.0.0.27 → 7000 … 8000 …… 9000
  packets fully interleaved on the wire

  ✓ 10.0.0.14  door "ssh" opened
  ✓ 10.0.0.27  door "ssh" opened

# validate a real config
$ cargo run -- --check --config knockd.toml
deb

Debian / Ubuntu

sudo dpkg -i knock-daemon_<ver>_amd64.deb — installs a disabled, hardened unit and an example config at /etc/knock-daemon/.

rpm

Fedora / RHEL

sudo rpm -i knock-daemon-<ver>-x86_64-…gnu.rpm — same layout, disabled by default so a fresh install never fail-loops.

bin

Any distro

Grab the static musl tarball, install -Dm755 knockd2 /usr/bin/, edit the config, then systemctl enable --now knockd2.

src

From source

cargo build --release --features capture-afpacket for the pure-Rust capture path.

Configure

A door is an ordered sequence and a way to open it.

Plain TOML. Complete the sequence within seq_timeout and the source IP is granted access. Pick the backend that fits your firewall.

nftables backendatomic · kernel timeout

Adds the source to a named allow-set as an element the kernel expires on its own — no shell, no userspace timer.

# knockd.toml
[firewall]
backend = "nftables"

[[door]]
name        = "ssh"
sequence    = ["7000/tcp", "8000/udp", "9000/tcp"]
seq_timeout = "10s"
nft_set     = "inet filter knock_clients"
cmd_timeout = "30s"   # element lifetime
command backendknockd-compatible

Runs your shell with %IP% substituted, and can auto-undo it after cmd_timeout. Drop-in for existing knockd recipes.

# knockd.toml
[[door]]
name          = "ssh"
sequence      = ["7000/tcp", "8000/udp", "9000/tcp"]
seq_timeout   = "10s"
open_command  = "nft add element … { %IP% }"
close_command = "nft delete element … { %IP% }"
cmd_timeout   = "30s"
